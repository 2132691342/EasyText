## 拆分验证

打开任意 .txt / .json / .md 文件，确认：

- 编辑器仍可正常打开、键入、自动换行、撤销重做
- F2 / Shift+F2 切换书签、跳转
- Alt+X 切列编辑模式
- 列编辑弹窗可插入文本 / 数字 / 日期
- Markdown 文件的「编辑/分屏/预览」三模式切换
- 右键菜单所有 25 个命令可点击
- 录制宏 → 键入 → 回放

如果以上任何一项失败 → 拆分回归。检查：
- `src/components/editor/composables/` 下对应 composable 是否有语法错误
- `src/components/editor/CodeEditor.vue` 的 `useEditorXxx()` 调用是否漏传依赖

## Bug #1 — bookmark F2 与 BookmarkPanel 不同步

**复现步骤：**
1. 打开文件 A.md，BookmarkPanel 留空
2. F2 在第 5 行加书签
3. 打开 SettingsView → 关闭后回到主界面
4. 关闭文件 A.md
5. 重新打开 A.md
6. 按 Shift+F2 跳下一个书签
7. **修复后**：跳到第 5 行
8. **修复前**：F2 找不到第 5 行的书签（BookmarkPanel 创建时未走 DB 同步）

**后端验证：** SQLite 草稿/书签/最近文件表存在 `easytext.db`，BookmarkPanel 创建的书签落表。

## Bug #2 — snippet 自动完成缓存失效

**复现步骤：**
1. 打开 SettingsView → 代码片段 → 新建（prefix=`xyz`、body=`X Y Z`）
2. 打开任意 js 文件，输入 `xyz` + 等待自动完成
3. **修复后**：弹出 `xyz` snippet 选项
4. **修复前**：snippet 缓存永久未失效，自动完成列表里没有

**回归保护：** composables/useEditorCompletion.ts 监听 `editorStore.snippets.length` 变化自动 invalidate。

## Bug #3 — SaveAll 静默失败

**复现步骤：**
1. 打开多个文件，故意把其中 1 个文件设为只读（chmod 444）
2. 全部修改后 Ctrl+Shift+S
3. **修复后**：toast 提示「已保存 N 个，失败 M 个：xxx」
4. **修复前**：toast 只显示成功，失败的文件静默不告知

**位置：** useFileOps.saveAll（不在 M3 拆分文件里，由 M5 自测覆盖）。

## Bug #4 — GetAppVersion 硬编码

**复现步骤：**
1. 打开 SettingsView → 关于
2. 确认版本号显示「2.0.0」（与 wails.json `info.productVersion` 一致）
3. **修复前**：显示「1.0.0」

**后端代码位置：** `backend/api/handler.go` 的 `loadAppVersionFromWailsJSON()`，在 NewHandler 时注入 `h.appVersion`；`api_dialogs.go` 的 `GetAppVersion` 读取 `h.appVersion`。

## Bug #5 — exit 与 close-to-tray 边界

**复现步骤：**
1. SettingsView 打开「关闭到托盘」开关
2. 菜单 文件 → 退出
3. **修复后**：应用真正退出（不留托盘）
4. **修复前**：被 OnBeforeClose 误判为"关闭到托盘"，窗口隐藏但不退出

**前后端协作：** useCommands.exit 先 `SetCloseToTray(false)` + `ForceQuit()`（closepolicy.SetForce），
再 `Quit()`。closepolicy.IsForced() 让 main.go OnBeforeClose 放行。

## Bug #6 — 文件外部修改走 watch 事件

**复现步骤：**
1. 打开文件 A.txt
2. 切到其它应用（VSCode / Notepad）修改 A.txt 并保存
3. 切回 EasyText
4. **修复后**：立即弹「文件已变更，是否重新加载」提示（无需先点窗口）
5. **修复前**：必须切换到 EasyText 窗口触发 `focus` 事件才检测

**实现：** MainLayout.vue 在 onMounted 注册 `file:change` 监听 + watch `ed.activeTab.path` 自动启 StartFileWatch。

## Bug #7 — lang-zh/en 提示文案

**复现步骤：**
1. 菜单 语言 → English（或 简体中文）
2. 确认 toast 提示「Language saved. Some UI strings require restarting EasyText to take effect.」
3. **修复前**：toast 显示「Switched to English. Restart to apply.」但实际多数字符串并不真的需要重启——文案误导

## Bug #8 — clear-history / fav-empty 文案

**复现步骤：**
1. 最近文件 / 文件夹 → 清空记录
2. 确认 toast 提示「最近文件记录已清空」
3. 菜单 文件 → 「清空最近文件记录」
4. **修复前**：菜单文案「清空历史记录」语义模糊（让人误以为是清空别的历史）

**fav-empty 占位：** 收藏夹为空时由 RecentFilesDialog 的空状态组件展示，不再 toast 弹「收藏夹为空」。
